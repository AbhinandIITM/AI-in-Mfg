# Course Deliverables

The written report and the slide deck.

| File | What it is |
| :--- | :--- |
| `report.tex` | The course report, LaTeX source |
| `report.pdf` | The compiled report |
| `presentation.tex` | The slide deck, Beamer source |
| `presentation.pdf` | The compiled deck |
| `presentation.pptx` | The same deck as a PowerPoint file, for editing |
| `make_ppt.py` | The script that generates the PowerPoint file |

## Building

```bash
cd report

# The report
latexmk -pdf report.tex

# The deck
latexmk -pdf presentation.tex

# The PowerPoint file
python make_ppt.py
```

The build artifacts are ignored, so only the sources and the deliverables are
tracked. The numbers in the report and the deck come from the artifacts in
`results/`, which are regenerated by `python agent/summarize_results.py`.
